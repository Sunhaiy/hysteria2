# 中秋·国庆活动中心（2026）

## 入口与边界

用户入口 `/portal/holiday`，管理员入口 `/admin/holiday`。
`HolidayCampaign` 默认关闭，迁移不启用活动、不修改历史订单。
`HolidayEntry` 记录参与及赠额、抽奖名额预占；普通商城和拼团不创建它。
充值使用 `WALLET_TOPUP` 独立订单类型，不触发普通套餐的比例返利；活动邀请固定返现独立处理。
活动套餐调用 Commerce / Entitlement 原有履约边界，不直接修改权益或额度桶。
金额为整数分，八折为 `8000` 万分比，服务端计算并校验。新活动默认八折；已保存活动需在后台将参与套餐更新为80%，历史付款快照不重算。

## API

新活动默认充值档位：26送5、38送6、50送8、68送12、100送20、200送45元，每人每档一次。
六档全部参与实充482元，赠96元，到账578元；全站赠额预算仍为1000元。
新活动订单每笔赠三次抽奖，无个人三次上限，付款时完整预占三份名额，不足时明确告知不赠机会。
活动期内新邀请注册赠邀请人一次，好友首次成功普通/活动充值补至累计三次；同一好友不重复发放。
独立抽奖票按来源幂等记录并共享全站500份库存。旧订单通过新增迁移保留原次数和已抽结果，不追补。
充值退款撤销相关未用机会，同时通过余额账本追回对应邀请现金与已中奖奖金；不足或账户不可用时转人工核验，不自动产生负余额。
后台活动设置新增邀请首次充值现金奖励，默认500分，0表示关闭现金奖励。活动期内新邀请好友首次满10元的外部充值触发（普通/活动充值均支持）。每位好友终身一次；注册时保存金额快照，有参与记录后不允许改变承诺金额。
HolidayInviteReward按活动/受邀人唯一记录奖励与来源订单。重复回调、再次充值或退款后充值不重新发奖；旧充值订单不补发。
现金发奖不占抽奖库存；收款用户不因邀请人余额溢出或账户异常而履约失败，邀请奖励进入后台人工核验列表。
仅有邀请票或邀请奖励记录也属于已参与，后台保存不得补满奖池、重置奖品或缩短承诺抽奖期限。
邀请注册Serializable冲突对整个注册事务有限重试；活动和普通充值共同检查完整承诺金额的余额容量，终止性异常进入退款补偿。
已保存且有参与记录的活动仍锁定原档位，历史订单按原快照履约，不自动增加赠额。

所有接口要求现有会话认证，写请求遵循现有 CSRF 规则。

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/portal/holiday` | 活动、价格、实时库存概率、本人资格及最近100条记录 |
| POST | `/api/portal/holiday/quote` | `offerId`、可选 `planActivation`，复用生效规则 |
| POST | `/api/portal/holiday/payments` | `HolidayPurchaseDto`，要求 `Idempotency-Key` |
| POST | `/api/portal/holiday/draw` | 抽奖，要求 `Idempotency-Key` |
| GET | `/api/admin/holiday` | 管理员配置、默认值、分项统计及退款核验队列 |
| POST | `/api/admin/holiday` | 管理员保存配置，`revision` 防止覆盖并发修改 |

付款提交包含 `kind=TOPUP/PLAN`、`tierId/offerId`、`paymentType`、
`revision`、`expectedPriceCents`、`expectsDraw`、`immediateConfirmed`，
以及套餐可选的 `planActivation`。不能使用余额充值，不接受优惠码或拼团字段。
外部支付复用原查询、验签、凭据快照和回调；继续付款使用原支付单查询接口。

## 一致性与退款

- 预占、履约、抽奖使用 Serializable 事务；竞争时重试整个事务。
- 活动行锁串行化预算与奖品库存；充值资格、参与及各阶段账本有稳定唯一键。
- 预算计数包含已履约承诺，仅明确关闭的未履约付款释放预占；本地超时不等于网关关闭。
- 已履约订单退款不恢复参加资格或个人抽奖配额。未用机会撤销，已抽奖金追回。
- 充值仅全额原路退款：核验无余额支出且可追回本金、赠额、奖金，再在同一事务中扣回并创建退款任务。
  网关确认前为 `REFUND_PENDING`，不得另行线下转账。
- 有消费或不足以追回时仅写 `reviewReason`，不扣钱、不提交退款。管理员在活动统计及原订单中核验。
  网关异常沿用原退款任务队列；问题解决前不能另行补款或重复转账。
- 在途订单按原价格、周期、生效快照履约；超时到账或被替代的支付完整补偿退款，不只发本金。
- 外部实收只计外部支付；充值本金、赠额、余额消费、套餐销售、奖金及退款分列，不能相加作为收入。
- 有参与记录后锁定充值档位、初始奖品库存，不得缩短已承诺的抽奖期限。
