# 服务端探测展示与手动选路

- Clash 普通订阅和 provider 订阅全部使用手动选择组；普通线路替代原自动优选，不再承诺自动故障转移。provider 的自动健康探测关闭，订阅文件更新仍保留。
- 客户端自己的“全部测速”按钮无法由订阅禁止。用户手动测速仍会按入口进行，不会使用网站缓存。
- 网站刷新不调用节点，读取 worker 已有健康快照。按 Node.serverId 选择稳定的在用代表入口，共享其检测耗时；该数值不是用户到节点的延迟，也不是纯网络 RTT。
- 服务器快照缓存 30 秒，同进程跨用户并发读取合并。3 分钟以上的样本不展示延迟。未绑定服务器的入口不猜测物理机器归属，不展示共享延迟。
- Hysteria2/VLESS 协议健康检查继续独立执行，既有后台协议检查请求不会被取消；不能因为一台机器响应正常就将其全部协议标为健康。
- 更新订阅后生效。已有客户端对组名的选择可能需要重新确认；原来的节点名称、连接参数、DNS、分流与权限不变。
