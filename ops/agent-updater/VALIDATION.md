- API：15 项新增测试及 1 项密钥迁移回归通过。PostgreSQL 测试使用本机数据库的
  隔离 schema，验证真实事务锁、并发领取、首台门禁、幂等重放、离线占位、
  回滚占位、取消、权限、CSRF、签名、下载归属与状态校验。新增迁移在隔离

- 更新器：Linux amd64 环境下 11 个顶层测试通过，包含 4 个崩溃恢复子场景。
  使用真实磁盘日志、原子符号链接替换和 HTTP 测试服务器；进程重启及健康
  检查依赖为测试替身，不声称完成真实生产 systemd 更新。
- 安装器：4 项测试通过，覆盖首次安装、启动失败恢复覆盖配置、错误架构、
  非 root Agent 拒绝。测试文件系统和 systemctl 均隔离。
- 构建：API/Web 生产构建及类型检查通过；相关源码 Lint 通过。
  独立更新器 Linux amd64 和 arm64 均交叉编译成功；arm64 未做原生运行测试。
- 页面：使用本地只读数据接口检查生产构建，验证版本选择、同架构全选、
  不同架构禁选、勾选顺序决定首台、回滚原因、浅色与深色主题。
  浏览器未对生产或真实节点下发更新。
